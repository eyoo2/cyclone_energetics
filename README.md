# cyclone_energetics
This is the analysis code I wrote for my Spring 2026 senior thesis: The Role of Radiative Processes on Cyclone Energetics, advised by Gabe Vecchi and Gabe Rios.

This repo is simply meant to be a reference for my thesis, as my notebooks are not self-contained. My code relies on private scripts & data provided by the Vecchi Group. Thus, private path names have been replaced with dummy strings. 

The notebooks are ordered and named after their relevant thesis sections. Feel free to contact me with any questions.

Any references and AI used to help generate my functions/code are cited in the comments.
